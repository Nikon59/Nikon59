- **Linux и Embedded:** Ежедневное администрирование Arch Linux; практический опыт работы с Debian и ALT Linux. Сборка OpenWrt из исходного кода (Buildroot), редактирование Device Tree (DTS) и работа с маршрутизаторами на базе MT7621/MT7981.
- **Системы Windows:** Установка, настройка и диагностика неисправностей десктопных версий Windows (Windows 95–11), а также базовая настройка Windows Server.
- **Программирование и скриптинг:** Написание скриптов на Python и Bash, базовый SQL, чтение и навигация по существующим кодовым базам на Java.
- **Прикладное машинное обучение:** Предобработка табличных данных, оценка качества моделей и экспорт в формат ONNX для локального инференса.

## Избранные проекты

- **[OpenWrt: поддержка D-Link DIR-1260 R1](https://github.com/openwrt/openwrt/pull/25233)** (Upstream PR #25233)  
  Адаптировал [исходный патч сообщества](https://github.com/Lucky1openwrt/openwrt/commit/b03f52df9c7f1b5490607926dbf0256065705f24) для маршрутизатора D-Link DIR-1260 Rev. R1 (MediaTek MT7621DAT) под актуальную кодовую базу OpenWrt. Исправил конфигурацию светодиодов, снял зашитое в DTS ограничение раздела прошивки в 40 МБ для использования всего объёма 128 МБ NAND (~100 МБ полезного пространства), включил поддержку USB host, а также проверил работу устройства и совместимость с официальными пакетами `kmod`.

- **[ML MedClass Experiments: мобильный манифест ONNX и сборка CLI](https://github.com/Nikon59/ml-medclass-experiments)** (форк `RedT0wer/ml-medclass-experiments`)  
  Участвовал в доработке основного Python-фреймворка для табличной классификации и расширил ветку форка (`feature/onnx-mobile-export`) для интеграции с мобильным клиентом: написал `generate_mobile_manifest.py` для выгрузки параметров Z-score нормализации, границ признаков и SHA-256 хешей моделей в `model_manifest.json`, а также настроил сборку автономных бинарников CLI (Linux/Windows) через GitHub Actions.

- **[Pancreatitis (Pancreolana): форк с локальным инференсом ONNX](https://github.com/Nikon59/Pancreatitis)** (форк `Pancreatitis`)  
  Доработал существующий Android-прототип для запуска локальных ONNX-моделей (ONNX Runtime 1.31.0) вместо текстовых эвристик сходства. Вынес независимую от Android логику в модуль `:core` на Java 17, обновил интерфейс на Material 3, убрал внешнюю облачную синхронизацию и предзаполненные файлы БД из ассетов (приложение работает с пустой локальной SQLite через автономную заглушку входа) и добавил локальное шифрование через Keystore.
